This section of the contributor docs is a collection of approved, public facing RFCs, kept as a record of design decisions.

To propose a new RFC, open a discussion in the [RFCs category of GitHub Discussions](https://github.com/strapi/strapi/discussions/categories/rfcs). See [CONTRIBUTING.md](https://github.com/strapi/strapi/blob/develop/CONTRIBUTING.md#request-for-comments-rfc) for details.
