The map shows every workspace package under `packages/` and the dependencies between them. It is generated at build time from the root `package.json` workspaces and each package's `package.json`. Only internal dependencies are drawn: production by default, dev and peer on demand.

<PackageGraph />

## All packages

The same data as a table. _Deps_ counts the internal production dependencies of a package; _Used by_ counts the internal packages that depend on it in production.
